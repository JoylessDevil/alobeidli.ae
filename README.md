# Abdalla Cyber Portfolio

A static terminal-style portfolio built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main website
- `styles.css` — main design
- `script.js` — mobile navigation and uptime counter
- `article.css` — blog article styling
- `articles/` — starter blog article pages

## Edit before publishing

Open `index.html` and replace:

- `your-email@example.com`
- `linkedin.com/in/yourprofile`
- `github.com/yourusername`
- `your location`
- About text
- Blog titles or dates if needed

## Upload to GitHub

1. Extract this ZIP.
2. Open your repository.
3. Choose **Add file → Upload files**.
4. Upload all files and folders from inside this project folder.
5. Commit the changes.
6. Open **Settings → Pages**.
7. Choose **Deploy from a branch**.
8. Select `main` and `/ (root)`.
9. Save.

## Custom domain

In **Settings → Pages**, enter your domain under **Custom domain** and follow GitHub's DNS instructions.
